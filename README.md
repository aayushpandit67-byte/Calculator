# Calculator

A simple and responsive calculator built using **HTML**, **CSS**, and **JavaScript**. This project performs basic arithmetic operations with a modern user interface and smooth user experience.

## Features

* Basic arithmetic operations: ( `+`, `-`, `*`,`/`)
* Interactive button effects ( onclick sound effect )
* Clear all (`AC`) functionality
* Delete/Clear current input (`C`)
* Decimal number support
* Responsive and modern UI design

## Technologies Used

* **HTML5** – Structure of the calculator
* **CSS3** – Styling, layout, and visual effects
* **JavaScript (ES6)** – Calculator logic and functionality

## How It Works

1. Users enter numbers using the calculator buttons.
2. Mathematical operators are used to create expressions.
3. Clicking the **=** button evaluates the expression.
4. **AC** clears the entire display.
5. **C** removes the current input or last entry.

## Usage

* Click the number buttons to enter values.
* Select an operator (`+`, `-`, `*`, `/`).
* Press `=` to calculate the result.
* Use `AC` to reset the calculator.
* Use `C` to clear the current entry.
